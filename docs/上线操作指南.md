# 上线操作指南：买服务器 + 申请域名 + 部署

面向：搭（CDA）· 个人主体（无营业执照）· 10 人内测 → 逐步放开

---

## 〇、先明确一件事：走哪条路

| | 方案 A：**香港轻量服务器 + 域名**（推荐） | 方案 B：国内服务器 + 备案 |
|---|---|---|
| 能否立刻用 | ✅ **买到当天就能上线** | ❌ 备案要 7–20 个工作日 |
| 需不需要备案 | **不需要** | 必须 |
| 个人主体可行吗 | ✅ 可以 | ✅ 可以（但不能有交易功能） |
| 国内访问速度 | 延迟 50–120ms，够用 | 更快 |
| 微信内打开 | 一般可以 | 更稳 |
| 价格 | ¥24–40/月 + 域名 ¥30–80/年 | 首年 ¥60–120，续费更贵 |

> **建议先走方案 A。** 备案期间网站不能用，而你现在的目标是让 10 个合伙人尽快用上。
> 等内测稳定了再走方案 B（那时也可以顺便办营业执照）。

**下面全部按方案 A 写。** 方案 B 放在最后一节。

---

## 一、买服务器（约 15 分钟）

### 选哪家

**腾讯云** 或 **阿里云** 都行。腾讯云的轻量控制台对新手更友好，下面以腾讯云为例；阿里云步骤几乎一样。

### 具体步骤

1. 打开 **cloud.tencent.com** → 注册/登录（**用你自己的手机号实名**，个人实名即可，不需要企业）
2. 顶部搜索框输入 **「轻量应用服务器」** → 进入产品页 → **立即购买**
3. 按下表选（**关键项已标粗**）：

| 选项 | 选什么 | 为什么 |
|---|---|---|
| **地域** | **中国香港** | **这是最重要的一项**。选香港才免备案；选内地就必须备案 |
| 镜像 | **Ubuntu 22.04 LTS**（或 24.04） | 生态新、命令通用。**不要选 CentOS**（已停止维护） |
| 套餐 | **2核 2G / 40G SSD / 带宽 3M** | 10 人用绰绰有余。流量包选最低档即可 |
| 时长 | 先买 **1 个月** 试 | 别一上来买三年 |

4. 付款（首月约 **¥24–40**）

### 买完立刻做两件事

**① 记下公网 IP**
控制台 → 轻量应用服务器 → 点进实例 → 复制 **「公网 IP」**（形如 `43.xxx.xxx.xxx`）

**② 放行端口**
左侧 **「防火墙」** → 添加规则：

| 应用类型 | 协议 | 端口 | 来源 |
|---|---|---|---|
| 自定义 | TCP | **80** | 全部 IPv4 |
| 自定义 | TCP | **443** | 全部 IPv4 |
| 自定义 | TCP | **8787** | 全部 IPv4（可选，先调试用；配好 HTTPS 后可删） |

> ⚠️ 不放行的话，浏览器会一直转圈连不上——这是新手最常卡住的地方。

### 设置登录方式

左侧 **「密钥/密码」** 或实例页的 **「重置密码」** → 设一个复杂密码，**记下来**。

## 二、买域名（约 10 分钟）

### 在哪买

**就在同一家买**（腾讯云 → 「域名注册」）。同平台解析更方便，也少一次实名。

### 选什么后缀

| 后缀 | 首年价 | 建议 |
|---|---|---|
| **`.com`** | ¥60–80 | **推荐**，最通用、最不容易被拦截 |
| `.cn` | ¥30 左右 | 便宜，但**个人注册 `.cn` 需要额外的实名材料**，稍麻烦 |
| `.xyz` / `.top` | ¥10 左右 | 便宜，但部分平台会降低信任度 |

> 首次买就选 **`.com`**。贵不了几十块，省心。

### 起名建议

- 短、好念、别用生僻字
- 别包含他人商标（如 `nikexxx.com`）——会被投诉
- 例如：`cda-dress.com`、`dapei-app.com`

### 步骤

1. 腾讯云 → **域名注册** → 搜索你想要的域名 → 加入购物车
2. **创建信息模板**：填你的姓名、身份证号、手机号、邮箱
   （个人注册就这样，**不需要营业执照**）
3. 付款（¥60–80/年）
4. **等实名审核**：通常 **几小时到 1 天**。审核通过后域名才能解析

> ⚠️ 域名实名是**注册局要求**，与 ICP 备案是两件事。买香港服务器**只做实名、不做备案**。

---

## 三、域名解析（约 5 分钟）

等实名通过后：

1. 腾讯云 → **DNS 解析 DNSPod** → 找到你的域名 → **解析**
2. 添加两条记录：

| 主机记录 | 记录类型 | 记录值 | TTL |
|---|---|---|---|
| `@` | A | **你的服务器公网 IP** | 600 |
| `www` | A | **你的服务器公网 IP** | 600 |

3. 等几分钟，然后在本机验证：

```bash
ping 你的域名.com
# 返回的 IP 应该等于你的服务器公网 IP
```

## 四、部署（约 20 分钟）

### 4.1 本机准备

在项目根目录执行（会打包前端）：

```bash
cd /Users/harmony/Desktop/dsh2/cda
bash scripts/deploy.sh --prepare
```

### 4.2 首次上传到服务器

脚本会问你服务器 IP 和域名，然后把代码与构建产物传上去：

```bash
bash scripts/deploy.sh --first 你的服务器IP 你的域名.com
```

它会自动：
- 装 Node 20 与 Nginx
- 建目录 `/opt/cda`
- 上传后端、前端产物、数据库目录
- 写好 systemd 服务（**开机自启、崩溃自动重启**）
- 配好 Nginx 反向代理到 8787

### 4.3 配 HTTPS（必须）

```bash
ssh root@你的服务器IP
apt install -y certbot python3-certbot-nginx
certbot --nginx -d 你的域名.com -d www.你的域名.com
```

证书**自动续期**，不用管。

完成后访问 **`https://你的域名.com`** 即可。

### 4.4 日常更新

改完代码后：

```bash
bash scripts/deploy.sh --update 你的服务器IP
```

会重新构建、上传、重启服务。

## 五、上线检查清单

- [ ] `https://你的域名.com` 能打开
- [ ] 页面是 **https + 小锁图标**（不是「不安全」）
- [ ] 注册一个测试账号能成功
- [ ] 手机 4G（**不是 Wi-Fi**）下也能打开——确认是真的公网可访问
- [ ] 邀请码够用（`apps/server/data/cda.db` 里查）
- [ ] **数据库已备份**（见下）

---

## 六、⚠️ 必须记住的三件事

### 1. 数据库就是全部资产

**`apps/server/data/cda.db`** 这一个文件包含所有用户、帖子、消息。
**务必定期备份**：

```bash
# 在服务器上
cp /opt/cda/data/cda.db /opt/cda/data/backup-$(date +%F).db
```

建议加个每日定时任务。

### 2. 邀请码控制注册入口

内测期靠邀请码控制谁能注册。查看与补充：

```bash
sqlite3 /opt/cda/data/cda.db "SELECT code, used_by FROM invites;"
```

### 3. 不要急着做支付

你的主体是**个人**——**不能做在线支付**（微信支付/支付宝都要企业主体）。
交易环节请引导到第三方平台（闲鱼/微店）完成。
代码里已按 Provider 模式预埋，拿到执照后接上即可。

## 七、以后再换国内服务器 + 备案

等内测稳定、打算正式推广时：

1. **先买国内服务器**（轻量，首年常有 ¥60–120 的优惠）
2. **提交 ICP 备案**：
   - 在云厂商的备案系统里提交（免费）
   - 需要：身份证、手机号、邮箱、服务器实例（须已购买 ≥3 个月）
   - 网站名称别用「商城」「交易」等词——**个人备案不允许经营性内容**，
     用「穿搭记录」「个人分享」这类描述
   - 等 **7–20 个工作日**
3. 备案通过后，把域名解析改到国内服务器 IP
4. 微信小程序：还需要**小程序备案**，且 `request` 域名必须是**已备案**的国内域名

> ⚠️ 若要做支付/小程序电商，**需要营业执照**（个体工商户也行）。
> 这是资质门槛，不是技术问题。

## 八、遇到问题怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 浏览器一直转圈 | 防火墙没放行 80/443 | 回控制台加规则 |
| 域名打不开但 IP 能开 | 解析没生效 | 等 10 分钟；`ping` 确认 IP |
| 打开显示 502 | 后端没跑起来 | `systemctl status cda` 看日志 |
| 显示「不安全」 | 没配 HTTPS | 执行 4.3 的 certbot |
| 改了代码没生效 | 没重新部署 | 跑 `deploy.sh --update` |
| `certbot` 报域名不可达 | 解析未生效或 80 未放行 | 先解决前两项 |
