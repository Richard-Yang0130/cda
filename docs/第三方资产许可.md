# 第三方资产许可

本目录记录项目使用的第三方 3D 资产及其许可原文出处。
**条款会漂移**（Quaternius、VRoid 等的许可页都改过），所以下载当日的页面快照
与许可名要一并记录，不能只写「免费」。

---

## MakeHuman 官方骨架与形变目标

| 资产 | 文件 | 体积 | 用途 |
|---|---|---|---|
| 基础网格 | `base.obj` | 1,749,303 B | 人偶网格（19158 顶点 / 172 命名分组） |
| 骨架定义 | `default.mhskel` | 117,790 B | 163 根骨骼 |
| 蒙皮权重 | `default_weights.mhw` | 897,521 B | 139 根骨头的官方权重 |
| 形变目标 | `targets/**` | 各 0.6 KB ~ 380 KB | 体型 / 围度 / 长度 |

**许可证：CC0 1.0 Universal（公有领域奉献）—— 允许商用，无署名义务。**

出处（均为仓库内原文）：
- <https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md>
- <https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md>

`LICENSE.md` C 节原文：「The base mesh and proxies / Targets and modifiers /
Textures / Clothes / Poses and expressions — released under CC0 1.0 Universal」；
D 节明确对导出物（FBX / OBJ / DAE / MHX2）不作任何主张。

文件内自带的许可标记（已核对）：
- `default.mhskel` → `"license": "CC0"`
- `default_weights.mhw` → `"license": "CC0"`
- 各 `.target` 文件头部注释 → 「This asset was explicitly released as CC0 in september 2020」

> ⚠️ **只取资产，不要打包 MakeHuman 的程序代码。**
> MakeHuman 的**程序**是 AGPL，与资产的 CC0 是两回事。
> 本项目只使用上述数据文件，通过自己写的解析器读取，不含任何 MakeHuman 代码。

### 获取方式

```bash
bash scripts/fetch-mh-rig.sh
```

资产不入库（实测约 7.4MB），存放在 `.assets/mh_rig/`，该目录已在 `.gitignore` 里。
脚本可重复运行，缺什么下什么。

> 已知问题：`measure-waisttohip-dist-decr.target` 上游 raw CDN 持续返回 404
> （GitHub API 能看到该文件、大小 195549B，但直链取不到）。
> 影响很小 —— 用同名的 `incr` 目标配**负权重**即可得到反向效果。

## 为什么不用这些（调研结论，避免以后重复踩）

| 候选 | 许可结论 |
|---|---|
| **SMPL / SMPL-X / STAR** | MPI **非商用**，且含 No Distribution 条款，禁止再分发。商用需 Meshcapade |
| **GHUM / GHUML** | 只有 Google 表单申请，**未公布许可证** → 视为不可用 |
| **three.js `Xbot.glb` / `Soldier.glb` / `Michelle.glb`** | 仓库内**无任何许可元数据**；Xbot 已由贡献者本人确认来自 Mixamo → 不可当 CC0/MIT 用 |
| **Mixamo** | Adobe 条款允许商用，但非开源、需 Adobe 账号，且**未授予「当独立资产再分发」的权利** |
| **VRoid** | 官方基础网格「is not CC0」；且**禁止**做「能生成/输出 VRoid 网格构成模型」的创建器类应用，需另谈 pixiv 授权 |
| **VRM 生态** | 不是统一许可，每个文件在 License Settings 里自选 → 必须逐文件读 |
| **Ready Player Me** | 公共服务已关停；历史条款为 CC BY-NC-SA（非商用） |
| **Meta MHR** | Apache-2.0，**可商用**，是合格的备选（198.9MB，带骨架+蒙皮+体型 blendshape）。本项目未采用，因为 MakeHuman 已在用、迁移成本更低 |
| **Anny (NAVER)** | 代码 Apache-2.0、资产 CC0，**可商用**；但 `anny[smpl]` extra 是非商用，务必避开 |

## 本项目自己的代码

用于读取上述 MakeHuman 数据格式（`.mhskel` / `.mhw` / `.target`）。
不含 MakeHuman 的源代码。
