# 服务器与域名方案

面向：搭（CDA）· uni-app H5 + 后续微信小程序 · 中国大陆用户

---

## 一、先理解一个硬门槛：ICP 备案

**只要域名解析到中国大陆的服务器，就必须 ICP 备案。** 这不是可选项。

| 事实 | 影响 |
|---|---|
| 备案主体分「个人」与「企业」 | 个人可备案，但**不能做经营性网站** |
| 备案周期 7–20 个工作日 | 备案期间域名不能解析到国内服务器，等于这段时间用不了 |
| **有在线支付/交易 = 经营性** | 个人备案大概率被驳回，或上线后被要求整改 |
| 微信小程序上线也需备案 | 且 `request` 域名必须是**已备案**的域名 |
| 微信/支付宝支付要求 | 主体一般需为**企业**并持有营业执照 |

### 由此得出一条关键结论

> **你现在没有营业执照，就不要做「在线支付」。**
>
> 正确做法：交易环节跳转到**第三方平台**（闲鱼 / 微店 / 微信小店）完成，
> 自己的站点只做「展示 + 试穿 + 跳转」。这样站点是**工具/内容**性质，
> 个人备案可以通过。

这也是很多小团队的实际做法，不是妥协，是合规前提下的最优解。

## 二、三个阶段，按需选择

### 阶段 1｜现在就能用：隧道（零成本）

已经在跑：`cloudflared tunnel --url http://localhost:5173`

| 优点 | 缺点 |
|---|---|
| 零成本、当天可用 | 地址随机、重启就变 |
| 无需备案、无需服务器 | 依赖你自己的电脑常开 |
| 有 HTTPS | 开发服务器，不能公开传播 |

**适合**：给同事/朋友看原型、收集反馈。**不适合**：长期挂给真实用户。

---

### 阶段 2｜几十人试用：香港/境外轻量服务器（免备案）

**这是「想尽快让用户用上」的最短路径。**

| 项目 | 规格 | 参考价 |
|---|---|---|
| 轻量应用服务器（香港） | 2 核 2G / 30G SSD / 3M 带宽 | ¥24–40/月，年付约 ¥288–400 |
| 域名 | .com / .cn | ¥30–80/首年 |
| HTTPS 证书 | Let's Encrypt 或云厂商免费证书 | ¥0 |

**优点**：免备案，买到当天就能上线
**缺点**：
- 国内访问延迟约 50–120ms，比国内机房慢
- 偶尔丢包（跨境线路波动）
- **微信内打开可能被拦截**，微信小程序无法用它做 request 域名

**适合**：网页版试用、给非微信渠道的用户。
**不适合**：微信小程序、要求支付、对速度敏感的场景。

---

### 阶段 3｜正式上线：国内服务器 + 备案

| 项目 | 规格 | 参考价 |
|---|---|---|
| 轻量服务器（国内） | 2 核 2G / 40G SSD / 3–5M 带宽 | 新用户首年 ¥60–120，续费 ¥300–600/年 |
| 域名 | .com / .cn | ¥30–80/首年 |
| 备案 | 个人 | ¥0（自行提交，7–20 工作日） |
| HTTPS | 云厂商免费证书 | ¥0 |
| CDN / OSS（可选，放静态图与模型） | 按量 | ¥10–50/月 |

**备案需要准备**：身份证正反面、手持照（部分省份）、手机号、邮箱、
网站名称与简介、服务器实例（须已购买 ≥3 个月）。

**推荐厂商**：阿里云、腾讯云（备案流程最成熟，有 App 全程引导）。

## 三、推荐路径

```
现在        cloudflared 隧道          给身边人看原型
  ↓
1–2 周内    香港轻量服务器 + 域名      给几十个用户网页试用（免备案）
  ↓
正式上线    国内服务器 + 域名 + 个人备案  面向国内用户
  ↓
有营业执照后  微信小程序备案 + 微信认证 + 接入支付
```

**不建议跳过阶段 2 直接备案**：备案要等 7–20 个工作日，
而香港服务器当天就能上线，先用起来收集问题更划算。

## 四、落地清单（照做即可）

### A. 买服务器（阶段 2）

1. 阿里云/腾讯云 → 轻量应用服务器 → 选**香港**地域
2. 镜像选 **Ubuntu 22.04**（比 CentOS 生态新）
3. 配置 2 核 2G 起步；带宽按 3M 起
4. 购买后在控制台**放行 80 / 443 端口**

### B. 买域名并解析

1. 同一厂商买域名（解析在同平台更省事）
2. DNS 添加 A 记录：`@` 和 `www` 都指向服务器公网 IP
3. 等待解析生效（几分钟到几小时）

### C. 服务器初始化

```bash
# 安装 Nginx 与 Node（构建用）
sudo apt update && sudo apt install -y nginx
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 建站点目录
sudo mkdir -p /var/www/cda
```

### D. 本地构建并上传

```bash
# 在项目里构建 H5 产物
cd apps/client
pnpm build          # 产物在 dist/build/h5

# 上传到服务器
rsync -avz --delete dist/build/h5/ root@<服务器IP>:/var/www/cda/
```

### E. Nginx 配置

```nginx
server {
    listen 80;
    server_name your-domain.com www.your-domain.com;
    root /var/www/cda;
    index index.html;

    # uni-app hash 路由：找不到的路径一律回落到 index.html
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 网格等大文件：长缓存 + 开启压缩（模型 2.5MB，压缩后约 1MB）
    location /static/models/ {
        expires 30d;
        gzip on;
        gzip_types application/octet-stream;
    }

    gzip on;
    gzip_min_length 1k;
    gzip_types text/css application/javascript application/json image/svg+xml;
}
```

### F. HTTPS（必须，微信内要求）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com -d www.your-domain.com
```

证书自动续期，无需人工维护。

## 五、成本汇总

| 阶段 | 服务器 | 域名 | 合计/年 |
|---|---|---|---|
| 1 隧道 | ¥0 | ¥0 | **¥0** |
| 2 香港 | ¥288–400 | ¥30–80 | **约 ¥320–480** |
| 3 国内 | ¥60–600 | ¥30–80 | **约 ¥90–680** |

**最省钱的正式上线路径**：国内轻量服务器首年优惠（¥60–120）+ .cn 域名（¥30）+ 免费证书 ≈ **¥100 左右首年**，代价是要等备案。

## 六、必须提前知道的风险

1. **备案期间网站不可用**（国内方案）——所以先用香港服务器过渡。
2. **个人备案不能有交易功能**——支付环节跳第三方，或等有营业执照。
3. **微信小程序是另一套要求**：需小程序备案 + 服务器域名必须是备案过的国内域名，
   且不能带端口、不能用 IP。香港服务器**无法**用于小程序。
4. **价格与规则会变** —— 上面的价格为大致区间，下单前到官网确认，
   尤其备案政策各省略有差异（以厂商备案引导页为准）。
5. **不要用共享 IP 的廉价虚拟主机**做小程序后端，可能因同 IP 其他站点违规被连带封禁。

---

## 七、给你的最小行动建议

**如果只有几十个用户要试**：先不用买任何东西，继续用 cloudflared 隧道，
把「我的空间」「交易跳转」等功能补完，再考虑买服务器。

**如果要正式给一批用户用**：
买 **腾讯云/阿里云香港轻量（2核2G，约 ¥24/月）+ .com 域名**，
按上面 D–F 部署，半天可上线，全程免备案。

**如果要长期做下去**：
同步启动国内服务器 + 个人备案（7–20 工作日），
备案通过后把域名迁回国内，速度和微信兼容性都会好很多。
